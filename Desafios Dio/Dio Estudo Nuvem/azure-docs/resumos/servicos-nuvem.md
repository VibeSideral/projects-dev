# Modelos de Serviço em Nuvem: IaaS, PaaS e SaaS

## Modelos:
- **IaaS (Infraestrutura como Serviço)**: Fornece recursos básicos de computação.
- **PaaS (Plataforma como Serviço)**: Permite desenvolvimento sem se preocupar com a infraestrutura.
- **SaaS (Software como Serviço)**: Aplicações prontas para uso.

## Modelo de Responsabilidade Compartilhada
- Cliente e provedor dividem responsabilidades sobre segurança, gerenciamento e operação.

## Casos de uso
- **IaaS**: Máquinas virtuais, redes, armazenamento.
- **PaaS**: Hospedagem de apps, APIs.
- **SaaS**: Office 365, OneDrive, Salesforce.
