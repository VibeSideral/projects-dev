# Introdução à Azure

A Microsoft Azure é uma plataforma de computação em nuvem que fornece uma ampla variedade de serviços: computação, armazenamento, redes, bancos de dados, IA, e muito mais.

## Principais Características
- Modelo de pagamento: Pay-as-you-go.
- Alta escalabilidade e disponibilidade.
- Ampla integração com ferramentas Microsoft.

## Casos de Uso Comuns
- Hospedagem de sites e APIs.
- Backup e recuperação de desastres.
- Machine Learning e Data Science.
